03 How I work

Idea to Production

The same four steps, whether it's an AI agent or a new ERP module.

  1. 01

    Find the repeated work

    Sit with sales, support and operations, map where the hours go, and check what competitors already do.

  2. 02

    Write it down

    A PRD with user stories, scope and one success metric, agreed before anyone builds.

  3. 03

    Build and ship

    Prototype in n8n with Claude Code and Cursor, then take it to production with engineering in sprints.

  4. 04

    Measure and improve

    Track adoption and funnels in GA4 and Mixpanel, then fix what people actually struggle with.
